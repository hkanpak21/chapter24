\section{Classifying the corpus}
\label{sec:tables}

This section reports the corpus in two layers. Tables~\ref{tab:party-unit} to~\ref{tab:family-party} cross-tabulate features against one another, with works in the cells by citation number. Tables~\ref{tab:scenario} and~\ref{tab:adversary} give one row per work, so that every cell above is traceable to the paper behind it. Every value comes from a fixed vocabulary settled before the pass began.

The cross-tabulations are the layer that carries an argument, because in them an empty cell is a combination nobody has published. The value \texttt{none} is an answer and not a missing entry, recording that a work constrains no party at all. Of the 115 works classified so far, 22 state no resource bound on any party, and 0 fall outside the frame in the sense that deleting every resource restriction leaves the main claim unchanged.

\emph{This is a partial pass. 115 of the corpus's works are classified; the remainder are not yet placed.}
