# Ontology schema

`onto.tsv` holds one fact per line: `subject, predicate, object, note, checked`.
It is generated by `lab/src/merge-onto.py` from the files beside it and from `lab/results/literature-ontology/`. `schema.tsv` lists every
allowed value with its type and a gloss. A work's id is its wiki slug when it has
a wiki page, and its sweep key otherwise.

## Predicates from a paper

| Predicate | Object type | Says |
| --- | --- | --- |
| `relevance` | relevance | core, peripheral or out, for the AI oracle definition |
| `treats-training-as` | training-model | how the work models the training procedure |
| `grants-access` | access-model | what the adversary or observer receives |
| `quantifies-over` | adversary-class | the class the result holds for |
| `charges` | resource | what the adversary pays |
| `conditions-on` | utility-condition | the success condition that keeps the notion non-vacuous |
| `uses-notion` | security-notion | the notion defined or used |
| `defines` | security-notion | the notion is introduced by this work |
| `assumes` | assumption | the hardness or modelling assumption |
| `concludes` | result-form | the form of the main result; the note states it in one line with its location |
| `addresses` | task | the task studied |
| `reports-in` | phrasing | how the result is stated |
| `author-decision` | author-decision | the author's decision, from `papers.tsv` |
| `in-group` | group | what the secret is and who holds it, from `papers.tsv` |
| `extends`, `converse-of`, `refutes`, `applies`, `precursor-of`, `systematizes`, `competes-with` | paper | relations between works |

A paper may carry several triples with the same predicate. A paper with two
results in different settings carries both, and the notes say which result each
belongs to.

## Predicates between any two nodes

Used by hand-entered facts, checked only for known nodes: `limit-of`,
`analogue-of`, `equivalent-to`, `modelled-on`, `instance-of`, `proves-impossible`,
`proves-equal`, `separates`, `strengthens`, `queries`, `bounds`, `depends-on`,
`recovers-up-to`, `answers`, `uninstantiates`, `shares-property`, `cited-by`, `related`.

## checked

`wiki` taken from the work's wiki page, `sweep` from a sweep sheet, `pdf`
checked against the paper, `inferred` the coder's judgement, `hand` entered
during the discussion, `heuristic` an analogy, `to-verify` not yet checked,
`proposed` a slug a coder added that is not yet in `schema.tsv`.

## New entities

A coder that needs a value not in `schema.tsv` writes it as
`<slug> is-a <type> <gloss> proposed`. `views.md` lists every proposed slug for review.
