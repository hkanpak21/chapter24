# BC22

Chris Brzuska and Geoffroy Couteau. On Building Fine-Grained One-Way Functions from Strong Average-Case Hardness. EUROCRYPT 2022.

The full reading note is the wiki source page, which holds the summary, the
claim boundary, the quotations and the classification evidence:

    wiki/sources/fine-grained-one-way-functions.md

This file exists so a claim in `lib/claims.yml` that positions against BC22
can be traced from inside the project. It repeats nothing the wiki page holds.
