A reader arriving from machine learning security needs games, six adversary classes, and the two-party gap, and nothing else.

## Topic sentences, one per paragraph, in order

1. A security definition in cryptography is a game between a challenger and an adversary, and the advantage is measured against a baseline.
2. A security claim is a statement about some set of algorithms, and six such sets appear in this corpus.
3. Fine-grained cryptography asks for security against adversaries that exceed the honest party's resources by a stated factor.
