## About

Professor at Technische Universität Braunschweig at the time of the work catalogued here, working on machine learning for computer security — malware analysis, vulnerability discovery, binary code analysis — and on the methodology of that field. Senior author on the field's canonical statement of the pitfalls of learning-based security research.

## Contributions / Works

- **[Dos and Don'ts of Machine Learning in Computer Security (AQP+22)](../sources/dos-and-donts-ml-security.md)** (USENIX Security 2022, last author) — identifies ten pitfalls across the ML workflow, measures their prevalence in 30 top-tier security papers, surveys 135 of those papers' authors, and demonstrates experimental impact in four security domains. Pitfall P10, "Inappropriate Threat Model", is the field's canonical name for threat-model failure in learning-based security.
